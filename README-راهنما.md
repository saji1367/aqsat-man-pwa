# اقساط من — نسخه PWA

## انتشار روی GitHub Pages
1. فایل ZIP را استخراج کن.
2. تمام محتویات پوشه `aqsat-man-pwa` (خود فایل‌ها و پوشه `icons`) را در ریشه Repository گیت‌هاب آپلود کن.
3. در GitHub وارد `Settings > Pages` شو.
4. در بخش Build and deployment، گزینه `Deploy from a branch` را انتخاب کن.
5. شاخه `main` و پوشه `/ (root)` را انتخاب و Save کن.
6. پس از انتشار، آدرس GitHub Pages را با Chrome اندروید یا Safari آیفون باز کن.

## نصب
- Android: در Chrome منوی سه‌نقطه را باز کن و `Install app` یا `Add to Home screen` را بزن.
- iPhone: صفحه را در Safari باز کن، Share را بزن و `Add to Home Screen` را انتخاب کن.

## نکات توسعه
- برای هر انتشار جدید، مقدار `CACHE_NAME` در `sw.js` را تغییر بده (مثلاً `aghsat-man-v2`) تا فایل‌های جدید دریافت شوند.
- داده‌های فعلی در `localStorage` و روی همان مرورگر/دستگاه ذخیره می‌شوند. پاک کردن داده‌های سایت یا حذف مرورگر ممکن است آن‌ها را از بین ببرد؛ از پشتیبان‌گیری داخل برنامه استفاده کن.
- برای همگام‌سازی بین چند دستگاه، ورود کاربر یا پشتیبان ابری، در مرحله بعد باید بک‌اند و پایگاه داده اضافه شود.
- این نسخه یک PWA است؛ برای انتشار در Google Play یا App Store در آینده می‌توان درباره بسته‌بندی native تصمیم گرفت.
- برای نصب و Service Worker، سایت باید از HTTPS یا localhost ارائه شود؛ GitHub Pages این شرط را دارد.
